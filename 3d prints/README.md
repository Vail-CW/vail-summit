# Summit 3D models

These are the case parts for the Vail Summit public beta units. Print them, change them, make your own version. The case is a black clamshell that folds closed.

## STL files (`stl/`)

| File | Part |
|---|---|
| `Summit Screen Top Enclosure.stl` | Top half, holds the 4" screen |
| `Summit main body.stl` | Main body |
| `Summit bottom of case, battery edition.stl` | Bottom of the case, with room for a battery |
| `Summit rear access door.stl` | Rear access door |
| `summit Keyboard Main.stl` | Keyboard housing |
| `keyboard top trim.stl` | Keyboard top trim |
| `keyboard base trim.stl` | Keyboard base trim |

## Project files

The `.3mf` files in this folder are the slicer project files for the same parts, if you'd rather start from those.

The current case, PCB, and firmware all support capacitive touch keying, but the touch pads are not installed on current units. If you design a case that exposes them, I'd love to see it.
